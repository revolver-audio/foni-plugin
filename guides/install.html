How to install FONI, step by step

FONI is free and the installers are not code-signed yet, so Windows and macOS show a warning the first time. Here is exactly what you will see and which buttons to press. It takes about a minute.

WindowsmacOSFind FONI in your appTroubleshootingWhy the warning?

Windows

  1. Download FONI-0.9.3-Windows-Setup.exe from the download section and double-click it.
  2. A blue window may appear:
    Windows protected your PC
    Click More info (the small link under the text), then Run anyway.
  3. Windows asks whether to allow the app to make changes. Click Yes: the installer needs this to copy the plugin into the shared plugin folders.
  4. Tick the formats you want (VST3, CLAP, Standalone) and click through to Finish.
FormatInstalled to
VST3C:\Program Files\Common Files\VST3
CLAPC:\Program Files\Common Files\CLAP
Standalone appC:\Program Files\Revolver Audio\FONI

To uninstall: Settings → Apps → Installed apps → FONI → Uninstall.

macOS

  1. Download FONI-0.9.3-macOS.pkg and double-click it.
  2. macOS stops it with a message like:
    “FONI-0.9.3-macOS.pkg” Not Opened — Apple could not verify it is free of malware…
    Click Done (not Move to Trash).
  3. Open System Settings → Privacy & Security and scroll down to the Security section. You will see a line saying the FONI installer was blocked. Click Open Anyway.
  4. Confirm with your Mac password (or Touch ID) and click Open Anyway once more. The installer now opens normally.
  5. Choose the formats (VST3, AU, CLAP, app) and click Install.

On older macOS versions (before macOS 15 Sequoia) you can also right-click (Control-click) the .pkg, choose Open, then Open again. On macOS 15 and later that shortcut no longer works: use System Settings as above.

Find FONI in your app

After installing, the app you edit in has to scan for new plugins. Restarting it is usually enough; if FONI does not show up, use the rescan option.

AppWhere FONI appears
Audacity 4Effect → VST3 → Revolver Audio → FONI (tested by us). If it is missing, open the plugin manager and rescan.
REAPERAdd FX to the voice track and search “FONI”. If missing: Options → Preferences → Plug-ins → VST → Re-scan.
Logic Pro / GarageBandAudio Units → Revolver Audio → FONI. The first time, Logic validates the plugin in the background.
Other VST3 / CLAP hostsLook for Revolver Audio or FONI in the effects list after a rescan.

Put FONI on the voice track, after any noise reduction, pick a preset, and play a minute of speech: the meter shows On target once the output has settled. Every control is explained in the user guide.

Troubleshooting

Windows: there is no “Run anyway” button

Click the More info link first; the button appears after it. If your computer is managed by an employer or school, an administrator may have blocked unsigned apps.

Windows: my browser says the file “isn't commonly downloaded”

In Edge or Chrome, open the downloads list, choose Keep (Edge: “…” → Keep → Show more → Keep anyway). New free apps get this until enough people have downloaded them.

macOS: there is no “Open Anyway” button

The button only appears for about an hour after you tried to open the installer. Double-click the .pkg again, click Done, then go straight to Privacy & Security.

FONI does not show up in my app

Check the format: Audacity 4 and most Windows hosts use VST3; Logic and GarageBand use AU. Make sure you ticked that format in the installer, then rescan or restart the app. FONI is 64-bit only.

Pro Tools

Pro Tools only loads AAX plugins. FONI does not have an AAX version yet.

Why the warning?

Windows and macOS warn about any installer that is not signed with a paid developer certificate. FONI is a free project and its installers are not signed yet; that is the only reason for the message. The installers are built automatically from the source code on GitHub's build servers, and you can always download the latest one from the official releases page. Signed installers are planned.
